# Saxo_Broko
The official website code for https://saxobroko.com (Hosted by Cloudflare Pages project `saxobrokowebsite`)

![Uptime](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/saxobroko/saxostatus/master/api/alt/uptime.json)

## Develop

```bash
npm install
npm run start    # Eleventy dev server
npm run build    # output → _site/
```

See [CLOUDFLARE.md](CLOUDFLARE.md) for Pages build settings (build command `npm run build`, output `_site`, Node 20).
